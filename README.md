First Project in Second Semester
After completing my first semester in computer science, I began solving a problem I noticed in my surroundings. In our country, some departments still operate manually. I gathered information about the problem and explored potential solutions.

After understanding the basics, I combined the knowledge I had gained during my first and second semesters. Initially, I solved the problem in a file that ran in the terminal. Later, I modified it using Object-Oriented Programming (OOP) and achieved good results.

To improve clarity and organization, I separated the file into three or four parts and called all the methods or functions in the main file. Additionally, I designed a rough GUI for the project. While I know it still requires many changes, at this stage, I applied all the knowledge I had gained.
